# GiftLink User Stories

## User story template

As a **[type of user]**, I want **[goal]**, so that **[reason/value]**.

## Initial stories

1. As a visitor, I want to browse available gifts so that I can find useful free items.
2. As a user, I want to register so that I can create an account.
3. As a user, I want to log in securely so that my account is protected.
4. As a user, I want to search items by keyword so that I can find relevant items.
5. As a user, I want to filter items by category so that I can narrow results.
6. As a user, I want to view item details so that I can decide whether an item is useful.
7. As a user, I want to list an item so that another person can reuse it.
8. As a user, I want to edit my profile so that my information stays current.
